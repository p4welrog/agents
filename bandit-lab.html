How to use Bandit Lab

What is this for?

A multi-armed bandit is the simplest learning problem with the exploration–exploitation dilemma: several slot machines, each paying +1 with an unknown probability. Every pull either exploits what you already know or explores to learn more.

In the lecture's terms, the machines are an unknown, stochastic, sequential environment; the reward is the critic's feedback; and deliberately trying a machine that looks worse is the problem generator at work.

Play mode
  • Pull a lever by clicking Pull or pressing 1–8. Each pull shows +1 or 0.
  • With statistics on, each machine shows your estimate of its odds (dot) and how uncertain it is (bar): the fewer pulls, the wider the bar.
  • When the pulls run out, the true odds are revealed and your result is compared with several strategies on the same machines.
  • Replay these machines keeps the same hidden odds; New machines draws new ones.
  • Who plays? hands the game to an algorithm. Use Step to see, pull by pull, why it chose that machine.
Strategy lab

Runs the selected strategies on hundreds of random bandits and plots the averages:

  • Regret: how much reward was lost compared with an agent that knew the best machine from the start. A curve that flattens means the strategy has found the best machine; a straight line means it keeps losing at a constant rate.
  • Best machine chosen: the share of runs pulling the truly best machine at each step.

Change one setting at a time and explain the difference.

The strategies
  • Random: pure exploration. The baseline to beat.
  • Greedy: always pulls the machine with the best average so far. Pure exploitation.
  • ε-greedy: greedy, but with probability ε pulls a random machine.
  • ε-decreasing: explores a lot at first and less over time (ε = 1/√t).
  • ε-greedy, recency-weighted: like ε-greedy, but its estimates weight recent pulls more (step size α = 0.1), so it can follow odds that drift.
  • UCB1: “optimism under uncertainty”: picks the machine with the highest upper bound, average + bonus that is large for rarely tried machines. UCB, tuned uses a smaller bonus.
  • Thompson sampling: for each machine draws a plausible value of its odds from its posterior distribution and pulls the highest draw: explores exactly as much as its uncertainty justifies.
Key terms
  • Exploitation: using current knowledge to get reward now.
  • Exploration: gathering information that may pay off later.
  • Estimate: average reward of a machine so far (wins ÷ pulls).
  • Regret: expected reward lost compared with always choosing the best machine.
  • Stationary / non-stationary: the odds stay fixed / drift over time.
