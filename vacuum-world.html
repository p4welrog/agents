How to use Vacuum World Lab

  

    
What is this for?

      
A tiny world from Russell & Norvig, ch. 2: a few squares that can be dirty and a robot vacuum. You decide what the robot can sense, how the world behaves and how success is measured, then watch different agent programs live in it.

      
The goal is not to clean well. The goal is to see why an agent is rational in one environment and irrational in another.

    

    
A good way to work

      
    
        
  1. Set up a challenge (Challenges tab), or change one setting yourself.
    2. 
        
  2. Predict before you run: what will the agent do? Which score will be high?
    3. 
        
  3. Run slowly or Step through it, then Run to end for the final score.
    4. 
        
  4. Explain the result in terms of percepts, internal state and the measure. Use the Hint if you are stuck, then What to notice.
    5. 
        
  5. Change one thing at a time and use Compare all agents to test your explanation.
    6. 
      

    

    
What is on the screen

      
    
        
  • World: the true state (squares, dirt, robot). The agent never sees this picture.
    • 
        
  • Percept / Action: what the agent sensed this step and what it decided.
    • 
        
  • Performance measures: three scores of the same run; the highlighted one is the measure you selected. The chart shows it over time.
    • 
        
  • Inside the agent: its internal state (if it has any).
    • 
        
  • Recent steps: the last 12 percept → action pairs, newest on top.
    • 
        
  • Compare agents: all agents on the same 20 worlds.
    • 
      

      
Every  button explains the element next to it.

    

    
Controls and shortcuts

      
    
        
  • Run / Pause: Space. Step one action: →. Run to end: finish the lifetime instantly.
    • 
        
  • Reset: same world again from the start (same seed).
    • 
        
  • Speed: steps per second while running.
    • 
        
  • Copy link to this setup (Setup tab): the address encodes all settings, so the link reproduces exactly this world.
    • 
        
  • This guide: ?. Close it with Esc.
    • 
      

    

    
The agents

      
    
        
  • Simple reflex: reacts to the current percept only (Dirty → Suck, otherwise move).
    • 
        
  • Randomised reflex: like reflex, but moves left or right at random on a clean square.
    • 
        
  • Model-based reflex: keeps an internal map of what it believes about each square; can localise itself without a location sensor.
    • 
        
  • Dust recycler: designed to exploit one particular measure.
    • 
        
  • Custom rules and Custom JavaScript: your own agents (Agent program tab).
    • 
      

    

    
The performance measures

      
    
        
  • Clean squares: +1 for every clean square at every step (Russell & Norvig's measure).
    • 
        
  • Dirt removed: +1 each time dirt is sucked up.
    • 
        
  • Clean − moves: clean squares minus 1 for each move (energy cost).
    • 
      

      
The agents do not see the measure. Choosing it is your job as designer, and the same behaviour can be excellent under one measure and absurd under another.

    

    
Writing your own agent

      
Rules build a simple reflex agent: checked top to bottom, the first matching rule wins, no match = NoOp.

      
JavaScript can be any architecture. A model-based skeleton:


function agent(percept, memory) {
  if (percept.status === 'Dirty') return 'Suck';
  memory.t = (memory.t || 0) + 1;
  // internal state: what you believe about the world
  memory.seen = memory.seen || {};
  if (percept.location) memory.seen[percept.location] = memory.t;
  // ... decide where to go using memory
  return 'Right';
}

      
Errors and infinite loops are reported under the editor; nothing breaks the page.

    

    
Key terms

      
    
        
  • Percept: what the sensors deliver at one moment. Percept sequence: everything perceived so far.
    • 
        
  • Agent function: maps percept sequences to actions. Agent program: its implementation (what runs here).
    • 
        
  • Internal state: what the program remembers between steps.
    • 
        
  • Performance measure: evaluates the sequence of world states the agent causes.
    • 
        
  • Rational agent: chooses the action expected to maximise the performance measure, given its percepts and built-in knowledge.

Your function

      
function agent(percept, memory) is called once per step and must return the action.

      
percept

      
percept.location: 'A'…'E', or null when the location sensor is off.

      
percept.status: 'Dirty' or 'Clean'.

      
memory

      
An object that survives between steps: your internal state. Store anything JSON-like in it. Reset clears it. Its content is shown in ‘Inside the agent’.

      
Actions

      
'Left', 'Right', 'Suck', 'NoOp', 'Dump' (only if allowed in Setup).

      
Facts you may use

      
Squares are in a row, A on the left. Moving into a wall leaves you where you are. You do not get the number of squares as a percept: that is designer knowledge you may hard-code.

      
Debugging

      
Errors appear below. Use Step (→) and watch ‘Inside the agent’ to see your memory change. A step longer than 0.5 s is stopped.
